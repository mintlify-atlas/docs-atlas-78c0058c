---
title: Problem library
description: Browse, filter, and start practice sessions from all NeetCode 75, Blind 75, and NeetCode 150 problems.
---

The Problem Library tab gives you a browsable view of every problem across all three supported problem sets. You can filter by category and difficulty, search by title, and start a timed practice session directly from the list.

## Problem sets

<Tabs>
  <Tab title="NeetCode 75">
    The 75 core problems curated by NeetCode, organized by pattern. This is the Phase 1 target set. Each problem also indicates if it's part of the Blind 75.
  </Tab>
  <Tab title="Blind 75">
    The original Blind 75 list, a widely referenced set of high-signal interview problems. Problems that are also in the NeetCode 75 are labeled accordingly.
  </Tab>
  <Tab title="NeetCode 150">
    The extended 150-problem set used in Phase 2. Includes all NeetCode 75 problems plus harder additions. Problems that are part of the Blind 75 are labeled.
  </Tab>
</Tabs>

## Filtering and searching

- **Search by title** — type in the search box to filter problems by name in real time
- **Filter by category** — use the category dropdown to show only problems from a specific topic
- **Sort columns** — click the Status, Problem, or Difficulty column headers to sort ascending or descending

## Status indicators

Each row shows your current status for that problem:

| Indicator | Meaning |
|-----------|---------|
| Empty circle | Not yet solved |
| Check mark (amber) | Active — solved and in the SR review queue |
| Filled circle (green) | Retired — mastered and no longer in the review queue |

Clicking the status icon toggles a problem between solved and unsolved. Quick-marking a problem as solved logs it with a rating of 3.

## Starting a session from the library

Hover over any problem row to reveal the Play button on the right. Clicking it starts a timed practice session for that problem, identical to starting one from the Daily Plan.

## Reserved problems

<Note>
  Some problems are marked **Mock Only** with a lock icon. These problems have full in-app editor content (problem statement, examples, constraints, and optimal solution) and are reserved exclusively for Mock Interview mode. They do not appear as new problems in the Daily Plan.
</Note>
